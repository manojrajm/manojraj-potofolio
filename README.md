## 🌟 Highlights

- **Rigged 3D Mixamo Humanoid**: Persistent 65-bone Forward Kinematics character with section-driven transitions (breathing, code typing, directional pointing, presentation, and camera-facing wave).
- **Cyber Terminal Boot Loader**: Monospace developer boot sequence with real-time asset telemetry logs, live code matrix, and luminous ASCII branding.
- **Bento 16 Interactive Pipeline**: Screen-locked engineering process flow with GSAP ScrollTrigger and reactive 3D choreographies.
- **Global Reach Contact Hub**: Low-latency telemetry dashboard featuring dot-matrix world map radar hubs, live IST clock, and 1-click clipboard integration.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended, tested on Node v24)
- [npm](https://www.npmjs.com/) or [bun](https://bun.sh/)

### Installation

```bash
# 1. Clone repository
git clone https://github.com/manojrajm/manojraj-digital-architect.git
cd manojraj-digital-architect

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
